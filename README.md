# Transport Final Project 🚍

A simple one-page web application for booking transport in towns, aligned with **UN SDG 11: Sustainable Cities & Communities**.  
Users can book rides and view their bookings on the same page.

---

## 🧩 Features

- Single-page application (HTML, CSS, JavaScript all in one file)  
- Booking form: collects **name, email, pickup and dropoff locations, transport type**  
- **“My Bookings”** section: shows a table of all bookings made during the session  
- Lightweight and easy to host (GitHub Pages or any static host)
